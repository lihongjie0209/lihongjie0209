# Hi, I'm Li Hongjie

I build open-source developer tools for document automation, data workflows,
and reliable command-line experiences. Most of my recent work is in Rust and Go.

## Featured projects

- **[docx-jsx](https://github.com/lihongjie0209/docx-jsx)** — Describe Word
  documents with JSX/TSX, compile them to DOCX, and reverse supported DOCX files
  back to JSX. Built in Rust with an embedded V8 runtime and `docx-rs`.
- **[xlsx-jsx](https://github.com/lihongjie0209/xlsx-jsx)** — Describe Excel
  workbooks with JSX/TSX, build XLSX files, and reverse the supported
  lossless subset back to JSX. Built in Rust with an embedded V8 runtime.

## Current interests

Making Office documents reproducible and maintainable as code: explicit DSLs,
round-trip conversion, useful validation, and agent-friendly CLI interfaces.

Feedback and contributions are welcome through issues and pull requests on the
project repositories.
